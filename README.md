# 勇者サバイバー (fantasy survivor)

ヴァンパイアサバイバーズ系の見下ろし型オートバトル・ローグライト。
ファンタジー世界観、ブラウザ / Google Play 配信を想定したプロトタイプ。

## 実体

- **`index.html`** — ゲーム本体。単一ファイル（約176KB / 4,182行、うちJS 3,693行）
- 依存ライブラリなし（Canvas 2D + WebAudio + DOM のみ。フォントのみ Google Fonts）
- **ビルド不要。ブラウザで `index.html` を開けば動く。** ライブラリを足さない方針を維持する

## 引き継ぎ資料（別チャット・別セッションでも続きから作業するための資料）

| ファイル | 内容 |
|---|---|
| [`docs/HANDOFF.md`](docs/HANDOFF.md) | アーキテクチャ・実装済みシステム・**必須ルール**・未実装リスト・検証手順 |
| [`docs/TABLES.md`](docs/TABLES.md) | 武器22 / キャラ6 / 敵13 / ボス6 / パッシブ9 / 永続強化14 の全データテーブル |
| [`docs/check.py`](docs/check.py) | 編集後の必須検証（構文＋未定義＋重複）を1コマンド化したもの |

**新しいセッションを始めたら、まず `docs/HANDOFF.md` を読むこと。**
特に §4「実装上の必須ルール」は過去に実際に事故った内容なので必ず守る。

## 編集後の検証（毎回やる）

```bash
node --version           # node が必要
python3 docs/check.py    # 構文 + 未定義関数 + 重複定義 を一括チェック
```

`重複` が出たら危険（旧定義が残って新実装が無視される事故）。必ず0にする。
