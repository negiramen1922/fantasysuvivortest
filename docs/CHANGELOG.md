# 勇者サバイバー バランス調整ログ

> 各バージョンの調整内容をここにまとめる。**変更を入れるたびに追記する。**
> 実装の詳細（アーキテクチャ・必須ルール）は `HANDOFF.md`、データ表は `TABLES.md`。

## バージョン運用
- ゲーム内バージョンは `index.html` の `var VERSION`（例 `α1.0.06`）。**マージのたびに末尾を+1**する。
- リザルト画面と設定画面に `VERSION` を表示。
- お知らせ（`UPDATES` 配列）は**1枠内でバージョン見出しごとに変更点を掲載**（新しい順）。マージ時は `UPDATES` 先頭に新バージョンを追加し `VERSION` を一致させる。

## ver.α1.0.26
- 立ち絵を **騎士キャラ（`SELCH==='knight'`）専用** に限定。他キャラ（聖女など）は従来の簡易表示（`rotate(P.face)`＋丸い本体＋武器線）へ戻した。α1.0.25 で全キャラが騎士になっていた不具合の修正。
- 大剣の振りをゆっくりに：`SWDUR=0.42`（従来 0.26）。`doSlash` で `swingT=SWDUR`、`drawPlayer` の進行は `u=1-swingT/SWDUR`、振りかぶり比を 0.28 に。
- 「緑の輪が浮く」不具合を修正：`drawEnemyOutlines` はスライムの潰れ・跳ねに追従せず固定位置に色付きリングを描いていたため、body が跳ねると輪だけ残っていた。純関数 `blobHop(e)`（`air/dy/sx/sy` を返す）を新設し、`drawEnemy` と `drawEnemyOutlines` の両パスが同じ値で楕円描画するよう統一。跳ね量は `dy=-air*r*0.30`、潰れは `sx/sy=±0.18/∓0.10`。

## ver.α1.0.25
- プレイヤーの立ち絵を騎士に一新（`drawKnight`）：兜＋前立て（赤羽根）・胸当て・青タバード＋金紋章・肩当て・脚／ブーツ。`P.hurt` で被弾色。上下反転はせず `fl=Math.cos(P.face)<0?-1:1` で左右のみ反転、`P.moving` 中は歩行の上下ゆれ（bob）。
- 大剣（`drawGSword`）：通常は肩へ斜めに担ぐ（ローカル `rotate(-0.6)`）。攻撃時は `swingT`（`doSlash` で 0.26s セット、`swingDir` で左右交互）に応じて振りかぶり→振り抜きの弧を描き、残像スウッシュを付与。剣とスウィングは本体と同じ `fl` ローカル空間で描画するため左右反転に追従。
- スライム（`blob`）のぽよんぽよん：`drawEnemy` で `slAir=|sin(time*4.2+e.ph)|`（0=接地/1=空中）を算出し、接地で横広・低く（`sx=1.20,sy=0.80`）、空中で細く・縦長（`sx=0.88,sy=1.12`）＋跳ね上げ（`translate(0,-slAir*R*0.34)`）。暗い縁（アウトライン）と影も同じ潰れ・跳ねに追従。`e.frz>0` と溜め（`st==='wind'`）中は無効。図鑑の立ち絵（`drawS1Shape` 直呼び）には影響なし。

### 武器

- **ファイヤーボール（fire）**：弱すぎたので強化。
  - **標準で「敵に当たるたび爆発」するように変更**（以前は熟練/覚醒でのみ爆発）。
  - 爆発ダメージは直撃より低い（直撃 `dmg` に対し **爆発 = dmg × 0.5**）。
  - 爆発の基本半径 **64px**（`AREA` でスケール）。熟練「爆炎」で 88px、「大爆発」で 108px に拡大（＝範囲強化に役割変更。以前は爆発の有無を切り替える効果だった）。
  - 覚醒（追尾ではなく）：**爆発の範囲・威力 ×1.5**（以前の覚醒「当たるたび爆発」は標準化されたため差し替え）。

- **セイクリッドレーザー（laser）**：火力が高すぎたので弱体化。
  - 発射間隔 **1.40s → 2.00s**（頻度ダウン）。
  - 基本ダメージ **16 → 11**（火力ダウン）。

- **アイスブリザード（blizzard）**：
  - 発動間隔 **0.50s → 0.85s**（頻度ダウン）。
  - **展開時、足元に雪の結晶（六花）が残る演出を追加**（発動ごとに1〜2個、約1.2秒で消える。歩いた跡に霜が降りるイメージ）。`fx` の新種別 `snowc` / `drawSnowC()`。

- **ブラックホール（voidh）**：吸引メイン・火力ほぼなしへ。
  - ティックダメージ基本値 **6 → 2.2**。
  - **中心からの距離減衰を追加**（`h.dmg × (1 − 距離/半径)`。外周ほぼ0、中心のみ痛い）。
  - 覚醒「特異点」の爆発倍率 **×14 → ×32**（低くなった基本値ぶんを補正し、爆発のご褒美感は維持）。

- **ホーリーランス（holy）**：拡散後ダメージ **親の45% → 30%**（半分以下に）。

### 射程システム（新規）

- **武器に射程（届く距離）の概念と、伸ばせる強化軸「射程」を追加**。
  - 軸 `range`：**+20%/Lv**（届く距離・飛距離）。`AXN/AXT` に追加、対象武器の `WAX` に `range` 上限を付与。
  - 基本射程テーブル `WRNG`（カテゴリ：近接／中／長）と、倍率 `RNGM(w)`・実距離 `RNG(w)` を追加。
  - カテゴリ分け：
    - **近接**：大剣・鎌・チャクラム・チェンソー（射程軸なし。範囲軸で届く範囲が伸びる）
    - **自己中心/設置**：焔輪・ブリザード・ベル・レーザー・審判の剣（射程軸なし。範囲で管理）
    - **中射程**：ダークハンド(360) / ダイナマイト(560) / グランドアッパー(640) / マスケット(440)
    - **長射程**：チェインライトニング(720) / ドラゴンボルト(660) / ファイヤーボール(840) / アイスジャベリン(860) / 弓(940) / ホーリーランス(860) / ロックボール(900) / ガトリング(900)
  - 実装：各武器の索敵半径 `nearest()` を `RNG(w)` に、飛翔体の寿命を「射程/弾速」または `×RNGM(w)` に変更（射程を伸ばすと弾が実際に遠くまで届く）。
  - 新規武器カードに `［近接/中射程/長射程］` を表示。

- **間合いによる火力補正を追加**（`WCLASS`／`CLMUL`／`RCM(w)` を `DMG(w)` に内包）。近接ほど高く、遠距離ほど低い。
  - **近接 ×1.15 ／ 自己中心 ×1.0 ／ 中射程 ×1.0 ／ 長射程 ×0.78**（近接:遠距離 ≒ 1.15:0.78 ≒ 1.47倍差。ユーザー提案「近接1・遠距離0.7」に近い設定）。
  - **武器のカテゴリを再整理**：チャクラム＝**自己中心**（近接から変更）／鎌（scythe）＝**中射程**（射程軸`range:2`・`WRNG`追加、投擲距離も射程で伸長）。近接は大剣・チェンソー。
