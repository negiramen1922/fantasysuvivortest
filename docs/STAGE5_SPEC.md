## 1. コンセプト

思い通りに止まれない氷の大地。敵の強さより **自分の足元** が敵になる。
①〜④が「敵の種類」で差を付けてきたのに対し、⑤は初めて**プレイヤーの操作そのもの**に手を入れる。

ここで作る部品（床パッチ・全画面フィルタ・壁ギミック・属性耐性）は
⑥砂漠（砂嵐＝フィルタ／蟻地獄＝パッチ）、⑦火山（溶岩＝パッチ）、⑩宇宙（無重力＝慣性の全面版）で
そのまま再利用する。**⑤の実装は⑥以降のインフラ作り**でもある。

## 2. 固有ギミック（4つ）

### 2-1. 氷結床（`icePatch`）★中核

ワールドに固定配置された円形の氷。**中に入ると慣性が付く**。

| 項目 | 値 |
|---|---|
| 配置 | 座標ハッシュ `ghash(ix,iy)`（散らし物と同じ方式）。セル 320px・出現率 38% |
| 半径 | 64〜120px（ハッシュで決定） |
| 慣性 | 氷上のみ。目標速度へ **毎秒 3.2 の割合で近づく**（≒0.3秒で追従）。氷外は現行どおり即時 |
| 見た目 | 青白い半透明の面＋縁のハイライト。地面レイヤー（`drawGround` の直後）に描く |

**実装が要るのはここだけ。** 現在の `movePlayer` は入力から直接 `P.x/P.y` を動かしていて
速度を持っていないので、`P.vx/P.vy` を追加する：

```js
// 氷上：目標速度へ寄せる（慣性）／氷外：従来どおり即時
var tvx=dx/d*spd(), tvy=dy/d*spd();          // d>0 のとき。d==0 なら目標は 0
if(onIce(P.x,P.y)){ var k=Math.min(1,3.2*dt); P.vx+=(tvx-P.vx)*k; P.vy+=(tvy-P.vy)*k; }
else { P.vx=tvx; P.vy=tvy; }
P.x+=P.vx*dt; P.y+=P.vy*dt;
```

- `reset()` で `P.vx=P.vy=0`
- 敵は慣性の対象外（挙動が読めなくなるため）。**プレイヤーだけが滑る**
- 「全面が氷」ではなく**パッチ**にする。全面だと理不尽、パッチなら「避ける／使う」判断が生まれる

### 2-4. 氷耐性（`eres`）

**氷ビルドへの初めての明確なカウンター。**

- ステージ全体で **氷属性ダメージ ×0.5**、**凍結（`frz`）の効果時間 ×0.4**
- 実装：`ETYPE` に `eres:{ice:0.5}` を持たせ、`hurt()` の属性乗算に1行足す。ステージ単位の指定も
  `STAGES[5].eres` で効くようにし、**敵個別 > ステージ** の優先で解決する
- **無効にはしない**（半減まで）。詰みは面白くない

### 図鑑テキスト（`DEX`）案

- 氷狼：凍った大地を駆ける狼。群れで一斉に距離を詰める。
- 雪男：分厚い毛皮の巨躯。遅いが押し返しが効かず、一撃が重い。
- アイスゴーレム：氷の鎧をまとった石人形。鎧を割ると氷片が飛び散る。
- 氷柱：地から生えた氷の柱。動かないが、近づくと氷の礫を撃つ。
- スノーワーム：雪の下を進む長虫。足元から突き上げてくる。
- フロストウィスプ：漂う冷気の精。触れられた者は足が鈍る。
- 雪だるま：転がる雪の塊。壊すと小さな二つに割れて追ってくる。
- 氷の弓兵：凍える矢を放つ射手。当たると体が重くなる。
- セイウチ：牙を構えて滑走する巨獣。助走を見たら進路から退くこと。
- 吹雪の精：吹雪に紛れて突っ切る精。群れで一直線に走り抜ける。

## 6. 解放条件・報酬（決定済み）

### 6-1. 解放条件

```js
var STGREQ={ 2:{stg:1,lv:20}, 3:{stg:2,lv:40}, 4:{stg:3,lv:60}, 5:{stg:4,lv:80} };
```

**ステージ④で Lv80 到達**。あわせて `STGNUM` は ⑤ まで既にあるので追加不要。

必要経験値を計算した結果（`xpNeed` の実装から算出）：

| 到達Lv | 累計XP | ザコ平均xp4.5 のときの必要討伐数 |
|---|---|---|
| Lv60（現行の④解放条件） | 16,177 | 約 3,600 体 |
| Lv70 | 26,201 | 約 5,800 体 |
| **Lv80** | **39,809** | **約 8,800 体** |

- Lv60 の **約2.5倍**の経験値が要る。20分完走での討伐数は終盤の湧きが急増する
  （`spawn`：20:00 時点で `burst=17` / `spawnT=0.24s`）ため到達は可能な範囲だが、
  **強いビルドと永続強化が前提**になる
- 経験値の倍率（パッシブ「経験」最大 +40%／図鑑ボーナス／キャラ成長）が乗ると
  必要討伐数は 6,000 体前後まで下がる
- 実装後のプレイテストで「④を完走しても Lv80 に届かない」となった場合は Lv70 へ引き下げるか、
  クリアベースへ切り替える。**この数値は要観察**

### 6-2. クリア報酬 その1：新武器「アヴァランチ（雪崩）」

ステージ⑤クリア（＝氷河の巨人グラキエス撃破）で解放。`WLOCK.avalanche = {cond:'stage', val:5}`。

**ステージのギミックをそのままプレイヤーの武器にする。** 2-3 の雪崩と実装を共有できる。

| 項目 | 内容 |
|---|---|
| 挙動 | 一定間隔で画面外から**雪の壁**が横断する。壁は敵を貫通して押し流し、通過中ずっとダメージ |
| 属性 | 氷（`ELW.ice` に追加） |
| 強化軸 | 攻撃力 / 範囲（壁の幅）/ 間隔 / 数（同時に走る壁の本数）/ 持続 |
| 熟練度 | 「なだれ込み」＝押し出し強化 ／「厚み」＝壁が太くなる ／ 剛・攻撃力 |
| 覚醒 | 「大雪崩」＝壁が十字（縦横同時）になる |
| 差別化 | 既存の氷武器はアイスジャベリン（貫通する単発槍）とブリザード（自機周囲の範囲＋シールド）。
  アヴァランチは**画面全体を横断する面**で、この挙動は現在どの武器も持っていない |

### 6-3. クリア報酬 その2：新キャラ「雪女」

## 7. 実装手順とテスト計画

### 手順（この順で1本ずつ検証する）

1. **氷結床**：`P.vx/P.vy` の導入と `onIce()`、地面レイヤーへの描画。まだ敵は増やさない
2. **属性耐性 `eres`**：`hurt()` に1行＋`ETYPE`/`STAGES` の指定
3. **ザコ10種**：`ETYPE` / `DEX` / `DEXLIST` / `MTAG` / 描画（`drawIceShape` を新設し `ICE5` 判定を `drawEnemy` と図鑑描画に配線）
4. **`WAVE5` / `STAGES[5]`**：`dev:1` を付けて先行マージ（`?dev=1` でのみ遊べる）
5. **ブリザードと雪崩**：`blizzardTick` / `avalancheTick` を `update()` の `umibozuTick` の隣に
6. **ボス4体**：`BOSS` へ追加。①は既存 charge、②③④は新 AI
7. **BGM `s5` / `s5b`**：`TRACKS` に2曲（③④が無音のままなので、そちらも同時に埋めたい）
8. `dev:1` を外して公開

### テスト（実装のたびに全部やる）

- `python3 docs/check.py`（本体スクリプトの構文＋未定義＋重複）
- Playwright でステージ⑤を起動 → 各時間帯のスクリーンショット（0:00 / 5:30 / 11:00 / 18:30）
- テストモードで20:00まで送り、ボス4体が順に出て名前が正しく切り替わること
- **氷結床**：氷の上で入力を止めても滑ること／氷外で即時停止すること／`reset()` 後に速度が残らないこと
- **負荷**：敵が溜まった状態で 60fps を維持（現行の計測手順）。氷結床の描画は
  `drawGround` と同じマス走査なので1フレーム20〜40枚に収まる想定
- **セーブ互換**：旧セーブ（`sgl` に 5 が無い）でクラッシュしないこと

## 9. 実装で仕様から変えた点（2026-08-22）

テストで問題が出たところだけ、仕様から数値・方式を変えている。

| 項目 | 仕様 | 実装 | 理由 |
|---|---|---|---|
| 氷結床の配置 | 円はマスの内側に収める | マスをはみ出させ、隣接9マスで判定 | 収めるとマスの境目に必ず氷の無い帯ができ格子状に見え、床の6.8%しか氷にならなかった |
| 氷結床の密度 | セル320px・出現率38% | セル280px・出現率55%（床の約17%） | 上の変更に合わせた再調整 |
| 氷結床の見た目 | 円 | ハッシュで揺らした多角形 | 真円＋放射グラデだと球（シャボン玉）に見えた |

### 途中で作った土台（⑥以降でも使う）

- `P.vx/P.vy`（速度）と `P.kx/P.ky`（外力）
- `icePatches` / `addIce()`（その場に生える床。⑦の溶岩でも使える）
- `blizzardTick` / `drawBlizzard`（全画面フィルタ＋風。⑥の砂嵐でそのまま使える）
- `avalancheTick` / `spawnAvalanche`（横断する壁。⑧の搬送ラインなどに転用できる）
- `slowApply()` / `frzApply()`（状態異常の付与を1箇所に集約）
- `capAlt`（同時数上限の代替敵をステージごとに指定）
- `near`（湧き円ではなくプレイヤーの周囲に配置）
- `?dev=1` の `window.DBG()` と、テストパネルの「冷気／吹雪／雪崩を出す／ボス撃破／ボスHP20%」

### 残っている判断

- **解放条件 Lv80**：④を完走しても届かない可能性がある。実プレイで確認してから確定する
- **`dev:1` を外すか**：外すと一般公開される。ブランチ上ではまだ付けたまま
