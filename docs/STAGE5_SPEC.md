## 1. コンセプト

思い通りに止まれない氷の大地。敵の強さより **自分の足元** が敵になる。
①〜④が「敵の種類」で差を付けてきたのに対し、⑤は初めて**プレイヤーの操作そのもの**に手を入れる。

ここで作る部品（床パッチ・全画面フィルタ・壁ギミック・属性耐性）は
⑥砂漠（砂嵐＝フィルタ／蟻地獄＝パッチ）、⑦火山（溶岩＝パッチ）、⑩宇宙（無重力＝慣性の全面版）で
そのまま再利用する。**⑤の実装は⑥以降のインフラ作り**でもある。

## 2. 固有ギミック（4つ）

### 2-1. 氷結床（`icePatch`）★中核

ワールドに固定配置された円形の氷。**中に入ると慣性が付く**。

| 項目 | 値 |
|---|---|
| 配置 | 座標ハッシュ `ghash(ix,iy)`（散らし物と同じ方式）。セル 320px・出現率 38% |
| 半径 | 64〜120px（ハッシュで決定） |
| 慣性 | 氷上のみ。目標速度へ **毎秒 3.2 の割合で近づく**（≒0.3秒で追従）。氷外は現行どおり即時 |
| 見た目 | 青白い半透明の面＋縁のハイライト。地面レイヤー（`drawGround` の直後）に描く |

**実装が要るのはここだけ。** 現在の `movePlayer` は入力から直接 `P.x/P.y` を動かしていて
速度を持っていないので、`P.vx/P.vy` を追加する：

```js
// 氷上：目標速度へ寄せる（慣性）／氷外：従来どおり即時
var tvx=dx/d*spd(), tvy=dy/d*spd();          // d>0 のとき。d==0 なら目標は 0
if(onIce(P.x,P.y)){ var k=Math.min(1,3.2*dt); P.vx+=(tvx-P.vx)*k; P.vy+=(tvy-P.vy)*k; }
else { P.vx=tvx; P.vy=tvy; }
P.x+=P.vx*dt; P.y+=P.vy*dt;
```

- `reset()` で `P.vx=P.vy=0`
- 敵は慣性の対象外（挙動が読めなくなるため）。**プレイヤーだけが滑る**
- 「全面が氷」ではなく**パッチ**にする。全面だと理不尽、パッチなら「避ける／使う」判断が生まれる

### クリオネの動き（この舞台の主役級ギミック）

「泳ぐように、シュッと動いては漂う」を繰り返す。**追尾しきらない**のがポイントで、
どこへ来るか読めないぶん、氷の上で避けようとすると自分から突っ込んでしまう。

| 状態 | 時間 | 挙動 |
|---|---|---|
| 漂う（`drift`） | 0.9〜1.3秒 | 速度30でゆっくり流れる。この間はほぼ止まって見える |
| 溜め（`tuck`） | 0.18秒 | 体を縮める。**この一瞬が予告** |
| 滑走（`dart`） | 0.30秒 | **340px/s** で直進。向きはプレイヤー方向 **±50度のランダム** |

- ±50度のブレが「翻弄」の正体。まっすぐ来ないので、こちらの回避が空振りする
- 体力は低い（110）ので、**止まって撃てば倒せる**＝氷結床の存在理由を1体で説明できる
- 見た目：半透明の体に赤い核。滑走中だけ頭のバッカルコーンが開く

### ダイオウグソクムシ（殻＝機動力）

既存のカニ（シールド持ちで遅い）／ヤドカリ（シールド持ちで速い）の**続き**として、
**「殻を割ると足が止まる」**という新しい形にする。

| 状態 | 速度 | 見た目 |
|---|---|---|
| 殻あり（shield 180 が残っている） | **150** | 丸まって転がるように移動 |
| 殻が割れた後 | **55** | 節を伸ばして這う。這った跡が分かるよう体を低くする |

- 「固いから遅い」ではなく「**固いから速い**」の反転。プレイヤーは
  「先に殻を割る（＝足を止める）か、無視して他を片付けるか」を選ぶことになる
- ヤドカリ（`hermit`：シールド140・速150）と数値が近いので、**HPと殻を一段上げて**差を出す

### 群れ（スウォーム）＝フロストウルフ

- `swarmK:'frostwolf'`、5:00 以降に発生
- **数は 14〜20 体**（既存の 32〜46 から減らす）。既存のスウォームはトビウオ・フライなど
  HP26〜30 の粒だったが、フロストウルフは HP120 あるため同じ数だと壁になってしまう

### 今回はずしたもの

| 名前 | 理由 |
|---|---|
| 氷狼 | フロストウルフに改名・統合 |
| 氷柱（設置型） | 動かない敵が盤面に溜まり、ペンギン・クリオネの「動きで魅せる」方向とも噛み合わない |

| セイウチ | 突進役がクリオネ・ペンギンと重なる。氷の海の大型枠はボスのシロガネで足りる |
| 吹雪の精 | 群れ役をフロストウルフに変更したため不要 |

### 図鑑テキスト（`DEX`）案

- アイススライム：凍った水たまりが動き出したもの。冷たいだけの、ただの塊。
- フロストウルフ：氷原を駆ける狼。群れで横一列に並び、一斉に走り抜ける。
- ペンギン：腹ばいで氷を滑る鳥。狙いもせず、ただ猛烈な速さで通り過ぎていく。
- クリオネ：氷の海を漂う小さな妖精。ふいに身を縮め、思わぬ方向へ滑り込んでくる。
- 雪だるま：転がる雪の塊。壊すと小さな二つに割れて追ってくる。
- 小雪だるま：雪だるまの割れた片割れ。小さいぶん素早い。
- アイスウィスプ：雪の精霊。遠くから氷の礫を放ち、当たった者の足を鈍らせる。
- スノーワーム：雪の下を進む長虫。逃げた先の足元から突き上げてくる。
- ダイオウグソクムシ：分厚い殻で丸まって転がる大虫。殻を割れば、もう速くは動けない。
- 雪男：分厚い毛皮の巨躯。遅いが押し返しが効かず、一撃が重い。
- アイスゴーレム：氷の鎧をまとった石人形。鎧を割ると氷片が飛び散る。

- 「滑らない」は `onIce()` の判定に `CH().noSlip` を見る1行で済む

### 6-4. 図鑑・タグ

- `DEXLIST` へ9種（分裂体 `snowmanS` を除く）、`BOSSDEX` へ4体
- `MTAG`：ビースト（氷狼・セイウチ・雪男）／精霊（ウィスプ・雪の女王）／巨人（アイスゴーレム・グラキエス）／竜（フロストドレイク）／アンデッドなし

## 7. 実装手順とテスト計画

### 手順（この順で1本ずつ検証する）

1. **氷結床**：`P.vx/P.vy` の導入と `onIce()`、地面レイヤーへの描画。まだ敵は増やさない

### テスト（実装のたびに全部やる）

## 9. 実装で仕様から変えた点（2026-08-22）

テストで問題が出たところだけ、仕様から数値・方式を変えている。

| 項目 | 仕様 | 実装 | 理由 |
|---|---|---|---|
| 氷結床の配置 | 円はマスの内側に収める | マスをはみ出させ、隣接9マスで判定 | 収めるとマスの境目に必ず氷の無い帯ができ格子状に見え、床の6.8%しか氷にならなかった |
| 氷結床の密度 | セル320px・出現率38% | セル280px・出現率55%（床の約17%） | 上の変更に合わせた再調整 |
| 氷結床の見た目 | 円 | ハッシュで揺らした多角形 | 真円＋放射グラデだと球（シャボン玉）に見えた |
| 氷狼 | HP150 / 速175 / 攻22 | HP110 / 速118 / 攻16 | 自動プレイの生存時間が ④27秒に対し ⑤12秒と明らかに外れていた（修正後23秒） |
| 雪男・セイウチ・ゴーレムの `cap` | 4 | 8 / 8 / 6、代替は氷狼→スノーワーム | 上限に当たった湧きが全部 氷狼 になり、終盤が172体中84体 氷狼 になっていた |
| 散らし物 | 氷柱の束 | 地面に伏せた割れた氷板 | 敵の「氷柱」と見分けが付かなかった |
| 雪崩の被弾 | 接触で34ダメージ | 1本につき1回だけ | 押し出しの向きが壁の進行方向と同じで壁の中に留まり、1本で130ダメージ（Lv1即死）になっていた |
| シロガネの残す氷 | （未指定） | 枚数24・半径60〜80・寿命14秒 | 最初の設定（40枚・74〜100・22秒）では盤面が氷で埋まった |
| アヴァランチの基礎攻撃力 | （未指定） | 22 | 9では壁が通り過ぎる0.4秒で2〜3回しか当たらず、単騎30秒で討伐2体だった（22で24体） |
| 凍結の倍率 | `eres` で凍結も短縮 | `frzMul` を別に用意 | ダメージ×0.5 と 凍結×0.4 は同じ係数では表せない |

### 途中で作った土台（⑥以降でも使う）

- `P.vx/P.vy`（速度）と `P.kx/P.ky`（外力）
- `icePatches` / `addIce()`（その場に生える床。⑦の溶岩でも使える）
- `blizzardTick` / `drawBlizzard`（全画面フィルタ＋風。⑥の砂嵐でそのまま使える）
- `avalancheTick` / `spawnAvalanche`（横断する壁。⑧の搬送ラインなどに転用できる）

- `capAlt`（同時数上限の代替敵をステージごとに指定）
