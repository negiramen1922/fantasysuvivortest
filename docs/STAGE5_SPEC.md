## 1. コンセプト

思い通りに止まれない氷の大地。敵の強さより **自分の足元** が敵になる。
①〜④が「敵の種類」で差を付けてきたのに対し、⑤は初めて**プレイヤーの操作そのもの**に手を入れる。

ここで作る部品（床パッチ・全画面フィルタ・壁ギミック・属性耐性）は
⑥砂漠（砂嵐＝フィルタ／蟻地獄＝パッチ）、⑦火山（溶岩＝パッチ）、⑩宇宙（無重力＝慣性の全面版）で
そのまま再利用する。**⑤の実装は⑥以降のインフラ作り**でもある。

## 2. 固有ギミック（4つ）

### 2-1. 氷結床（`icePatch`）★中核

ワールドに固定配置された円形の氷。**中に入ると慣性が付く**。

| 項目 | 値 |
|---|---|
| 配置 | 座標ハッシュ `ghash(ix,iy)`（散らし物と同じ方式）。**セル 600px・出現率 42%**（床の約14%） |
| 半径 | **128〜240px**（ハッシュで決定）。枚数を減らして1枚を大きくした（2026-08-25 変更） |
| 慣性 | 氷上のみ。目標速度へ **毎秒 3.2 の割合で近づく**（≒0.3秒で追従）。氷外は現行どおり即時 |
| 見た目 | 青白い半透明の面＋縁のハイライト。地面レイヤー（`drawGround` の直後）に描く |

**実装が要るのはここだけ。** 現在の `movePlayer` は入力から直接 `P.x/P.y` を動かしていて
速度を持っていないので、`P.vx/P.vy` を追加する：

```js
// 氷上：目標速度へ寄せる（慣性）／氷外：従来どおり即時
var tvx=dx/d*spd(), tvy=dy/d*spd();          // d>0 のとき。d==0 なら目標は 0
if(onIce(P.x,P.y)){ var k=Math.min(1,3.2*dt); P.vx+=(tvx-P.vx)*k; P.vy+=(tvy-P.vy)*k; }
else { P.vx=tvx; P.vy=tvy; }
P.x+=P.vx*dt; P.y+=P.vy*dt;
```

- `reset()` で `P.vx=P.vy=0`
- 敵は慣性の対象外（挙動が読めなくなるため）。**プレイヤーだけが滑る**
- 「全面が氷」ではなく**パッチ**にする。全面だと理不尽、パッチなら「避ける／使う」判断が生まれる

### クリオネの動き（この舞台の主役級ギミック）

「泳ぐように、シュッと動いては漂う」を繰り返す。**追尾しきらない**のがポイントで、
どこへ来るか読めないぶん、氷の上で避けようとすると自分から突っ込んでしまう。

| 状態 | 時間 | 挙動 |
|---|---|---|
| 漂う（`drift`） | 0.9〜1.3秒 | 速度30でゆっくり流れる。この間はほぼ止まって見える |
| 溜め（`tuck`） | 0.18秒 | 体を縮める。**この一瞬が予告** |
| 滑走（`dart`） | 0.30秒 | **340px/s** で直進。向きはプレイヤー方向 **±50度のランダム** |

- ±50度のブレが「翻弄」の正体。まっすぐ来ないので、こちらの回避が空振りする
- ④のミズチ（`ai:'serpent'`・うねって寄る）の一段上として、**寄り方そのものが読めない**形にした
- 見た目：半透明の体に赤い核。滑走中だけ頭のバッカルコーンが開く

### ダイオウグソクムシ（殻＝機動力）

④のカニ（盾持ちで遅い）／ヤドカリ（盾持ちで速い）の**続き**として、
**「殻を割ると足が止まる」**という新しい形にする。

| 状態 | 速度 | 見た目 |
|---|---|---|
| 殻あり（盾200 が残っている） | **150**（ヤドカリと同じ速さ） | 丸まって転がるように移動 |
| 殻が割れた後 | **55** | 節を伸ばして這う |

- 「固いから遅い」ではなく「**固いから速い**」の反転。プレイヤーは
  「先に殻を割って足を止めるか、無視して他を片付けるか」を選ぶことになる

### 群れ（スウォーム）＝フロストウルフ

- `swarmK:'frostwolf'`、**3:00 以降**に発生（`swarmStart:180`）。10〜16秒ごとに1回

- アイススライム：凍った水たまりが動き出したもの。冷たいだけの、ただの塊。

### ① 5:00 キングペンギン（`ai:'kingpen'`）

**役割：氷結床を教える。** ボス自身が止まれないので「滑る」が一目で分かる。
**3連続の追尾突進**と、**突進のたびに置き去りにされる弾**が主体。

#### 行動の一巡（約7秒）

| # | 状態 | 時間 | 内容 |
|---|---|---|---|
| 1 | 狙い（`pwind`） | 0.6秒 | **プレイヤーの方へ向き直り続ける**。赤い予告線が伸びる |
| 2 | 滑走（`pdash`） | 1.0秒 | **700px/s で直進**。方向は滑走が始まった瞬間に確定（＝イノシシと同じ） |
| 3 | 間 | 0.5秒 | 一瞬止まる。ここでプレイヤーは位置を立て直す |
| — | 1〜3を **3回** 繰り返す。**2回目・3回目は改めてプレイヤーを狙い直す** |
| 4 | 硬直（`prec`） | 2.2秒 | 動けない＝**反撃の窓** |

#### 置き去りの弾（この戦いの主題）

滑走中に**氷の礫を落としていき、それが後からバラバラに動き出す**。
1回目の突進で撒いた弾が、2回目・3回目の回避を邪魔する。

| 項目 | 値 |
|---|---|
| 落とす間隔 | 滑走中 0.13秒ごと（1回の滑走で **8発**） |
| 静止 | 落ちた場所に **0.6秒** 留まる（「置かれた」と読める時間） |
| その後 | **ランダムな方向へ 90〜140px/s** で漂い出す |
| 寿命 | 6秒（3回目の突進のときも約16発が盤面に漂っている） |
| 弾 | 半径7・ダメージ18 |

- 実装は既存の `eplace(x,y,dmg,hold,vx,vy,r,bk)`（設置弾：hold秒その場に留まり、その後動き出す）がそのまま使える。トレントの根攻撃で使っているもの
- **通った跡は氷結床になる**（半径60・寿命10秒）。ボス①が舞台の主題と繋がる唯一の接点なので残している。要らなければ1行消すだけ

> **追尾の強さについて**：既存のイノシシ／グレーターボアは「溜め中に狙いを定め、突進中は直進」で、
> 上の表もそれに合わせてある。滑りながら少し曲がってほしい場合は
> **毎秒40度まで曲がる**を足せる（1行）。どちらが良いか指示があれば合わせる。

### ② 10:00 フロストドレイク（`ai:'frostdrake'`）

**四足歩行の氷竜。** 役割：**シールドを割ってから殴る**を教える。

#### 行動のローテーション（1周 約13秒）

決まった順番で回るので、**覚えれば読める**。

| # | 行動 | 内容 |
|---|---|---|
| 1 | **大小弾幕バラマキ** | 溜め0.6秒 → **大弾10発**（半径13・弾速170・ダメージ×1.3）と **小弾18発**（半径6・弾速240）を全方位へ。0.25秒ずらして2波 |
| 2 | **ブレス** | 溜め1.2秒（赤い扇の予告）→ **扇状ブレス**（中心角±25°・射程420・0.8秒）。**命中で冷気2.5秒** → 硬直1.6秒 |
| 3 | **突進** | 助走0.7秒 → **620px/s で0.9秒**。四足で地を駆ける |
| 4 | **大小弾幕バラマキ** | 1と同じ |
| → | 1へ戻る（この切れ目でシールドの張り直し判定） |

#### シールド（この戦いの主題）

| 項目 | 値 |
|---|---|
| 初回 | 出現と同時に展開 |
| 張り直し | **割られてから12秒後**、ローテーションの切れ目で。動作1.0秒（この間は他の行動をしない＝殴れる） |
| 回数と値 | **3回まで。20,000 → 14,000 → 8,000** と減っていく |
| 効果 | シールドが残っているあいだ本体HPは減らない（既存の `hurt()` の盾処理をそのまま使う） |
| 実効HP | 230,000 ＋ 20,000＋14,000＋8,000 = **272,000** |

- **張り直しの値を毎回減らしているのは、火力の低いビルドが詰まないため。**
  一定値で張り直し続けると「DPSがシールド値÷間隔を下回ると永久に本体へ届かない」という壁になる。
  減っていく形なら、遅くても必ず終わる
- 張り直しは「割られてから12秒後」であって「12秒ごと」ではない。
  割れないまま放置されても増えないし、割った直後に即張り直されることもない
- **実装で1つ足りない**：現在のボスHPバーは本体HPしか出していないので、
  シールド量が見えない。バーの上に薄い盾ゲージを重ねるか、体の周りに氷の膜を描く必要がある

### ③ 15:00 雪の女王（`ai:'snowqueen'`）

**役割：動ける場所を奪う。** プレイヤーの周りに **氷の三重の檻** を張り、外から撃つ。

#### 行動のローテーション（1周 約14秒）

| # | 行動 | 内容 |
|---|---|---|
| 1 | **氷檻**（`qcage`） | 予告1.0秒（3つの輪が薄く見える）→ **プレイヤーを中心に三重の輪を設置**。同時に女王は**外周へ退く**（0.6秒で半径700の位置へ滑る） |
| 2 | **外周からの弾幕** | 檻が残っている10秒のあいだ、**1.3秒ごとにプレイヤー狙いの5発扇**（弾速215・ダメージ18）。弾は檻をすり抜けて中へ届く |
| 3 | **召喚** | 檻が消えたあと **アイスウィスプ4体**。ウィスプは遠距離なので、檻の外から撃ち続ける形になる |
| → | 2秒の間 → 1へ戻る |

#### 氷檻の作り

| 項目 | 値 |
|---|---|
| 半径 | **内 280 / 中 440 / 外 600**（画面の端近くまで使う「大きめ」の想定） |
| 壁の厚み | 26px |
| 切れ目 | **各リングに1ヶ所・40度**。ここだけが通れる |
| 切れ目の回転 | **内 +0.55 / 中 −0.38 / 外 +0.24 rad/s**。速さも向きも別々なので、**3つが揃う瞬間を待つ**ことになる |
| 接触 | 26ダメージ（無敵0.55秒。押し戻しはしない） |
| 寿命 | 10秒 |
| 中心 | **設置した瞬間のプレイヤー位置に固定**（追ってこない） |

- 中心がプレイヤーなので、設置直後は**3枚とも内側にいる**。外へ出るには切れ目を3回くぐる必要がある
- 逆に、**檻の中に留まったまま戦う**のも成立する（弾幕は5発扇なので避けられる）。
  「抜けるか、耐えるか」の選択になるのが狙い
- **弾ではなくリング状のゾーンとして作る。** 弾を並べて壁にすると
  半径280の輪だけで80発必要になり、3重で250発。読めないし重い

#### HP50%以下

- 檻の**内側に氷結床を1枚**生成（半径110・寿命12秒）。滑って切れ目を通り過ぎる
- 扇の間隔を 1.3秒 → **1.0秒**

> **常時オーラ（移動速度 −18%）は外すことを提案する。**
> 檻が「動きを制限する」役を担うようになったので、そのうえで常時鈍足まで乗ると
> 切れ目をくぐる操作が理不尽になる。残したい場合は **−10%程度**に下げたい。

## 6. 解放条件・報酬（決定済み）

### 6-1. 解放条件

```js
var STGREQ={ 2:{stg:1,lv:20}, 3:{stg:2,lv:40}, 4:{stg:3,lv:60}, 5:{stg:4,lv:80} };
```

**ステージ④で Lv80 到達**。あわせて `STGNUM` は ⑤ まで既にあるので追加不要。

必要経験値を計算した結果（`xpNeed` の実装から算出）：

| 到達Lv | 累計XP | ザコ平均xp4.5 のときの必要討伐数 |
|---|---|---|
| Lv60（現行の④解放条件） | 16,177 | 約 3,600 体 |
| Lv70 | 26,201 | 約 5,800 体 |
| **Lv80** | **39,809** | **約 8,800 体** |

- Lv60 の **約2.5倍**の経験値が要る。20分完走での討伐数は終盤の湧きが急増する
  （`spawn`：20:00 時点で `burst=17` / `spawnT=0.24s`）ため到達は可能な範囲だが、
  **強いビルドと永続強化が前提**になる
- 経験値の倍率（パッシブ「経験」最大 +40%／図鑑ボーナス／キャラ成長）が乗ると
  必要討伐数は 6,000 体前後まで下がる

  クリアベースへ切り替える。**この数値は要観察**

## 9. 実装で仕様から変えた点（2026-08-22）

テストで問題が出たところだけ、仕様から数値・方式を変えている。

| 項目 | 仕様 | 実装 | 理由 |
|---|---|---|---|
| 氷結床の配置 | 円はマスの内側に収める | マスをはみ出させ、隣接9マスで判定 | 収めるとマスの境目に必ず氷の無い帯ができ格子状に見え、床の6.8%しか氷にならなかった |
